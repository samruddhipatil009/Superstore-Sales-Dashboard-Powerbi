# Super-Store-Sales-Dashboard-Powerbi

### Overview
This Power BI dashboard analyzes Superstore sales data from 2019-2020 across products, regions, customer segments, and forecasts to help businesses make data-driven decisions.

### Key Metrics
- **Total Sales**: $1.6M
- **Total Profit**: $175K
- **Total Orders**: 22K
- **Avg Ship Time**: 4 Days
- **Time Period**: 2019 - 2020
- **Top State**: California
- **Top Region**: West - 33% of sales

### Key Insights
- **Regional Performance**: West Region leads with 33% sales, followed by East 29%, Central 22%, South 16%
- **Customer Segments**: Consumer segment drives 48% of sales, Corporate 33%, Home Office 19%
- **Payment Preference**: COD 43% is most used, followed by Online 35% and Cards 22%
- **Shipping Mode**: Standard Class dominates with $0.33M sales, followed by Second Class $0.11M
- **Category Breakdown**: Office Supplies $0.64M, Technology $0.47M, Furniture $0.45M
- **Top Sub-Categories**: Phones $0.20M, Chairs $0.18M, Binders $0.17M, Storage $0.15M
- **Seasonality**: Sales peak from September to November in both 2019 and 2020
- **State-wise Sales**: California leads, followed by New York, Texas, and Washington
- **Sales Forecast**: 15-day forecast shows continued growth trend into Jan 2021

### Tools Used
- Power BI for visualization and dashboard creation
- Microsoft Excel for data cleaning
- DAX for calculated measures
